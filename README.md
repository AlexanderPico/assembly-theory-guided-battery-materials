- Incubation date: 2026-05-15

## Current thesis

Treat Assembly Theory as a falsifiable descriptor family for battery-relevant molecular screening, not as a magical battery-discovery shortcut. The most credible first version is a molecule-level benchmark asking whether assembly-inspired features add predictive or ranking signal beyond standard cheminformatics and graph-based baselines.

## First milestone

Build a small reproducible benchmark around a molecule-centered dataset such as RedDB, comparing baseline descriptors versus baseline-plus-assembly features under scaffold-aware splits.

## Immediate next steps

1. Confirm dataset access and schema for RedDB or a comparable organic redox dataset.
2. Stand up a notebook or script that ingests SMILES and target labels.
3. Generate baseline RDKit and simple graph-complexity features.
4. Identify one trustworthy exact or approximate molecular-assembly implementation.
5. Run the first ablation with honest negative-result criteria.
